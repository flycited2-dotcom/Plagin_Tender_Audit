# Учёт тендеров — установка и подключение Google Таблицы

Два способа вести учёт, оба пишут в одну Google Таблицу:
- **Chrome** — расширение из папки `tender-tracker` (окно по иконке, список тендеров, экспорт в Excel);
- **Яндекс Браузер** — скрипт для Tampermonkey из папки `yandex` (кнопка «📋 В учёт» прямо на странице закупки).

## 1. Chrome: установка расширения

1. Откройте `chrome://extensions`.
2. Включите **«Режим разработчика»** (справа вверху).
3. **«Загрузить распакованное расширение»** → папка `tender-tracker`.
4. Закрепите иконку через пазл справа от адресной строки.

**После обновления файлов расширения** нажмите на его карточке в `chrome://extensions` круглую стрелку «Обновить».

Адрес таблицы и ключ берутся из `tender-tracker/config.js` (личный файл, на GitHub не выкладывается;
образец — `config.example.js`). Если файла нет — укажите их в расширении: **«Все тендеры» → «Google Таблица»**.

## 2. Яндекс Браузер: скрипт для Tampermonkey

В Яндекс Браузере (версия для организаций) нельзя поставить своё расширение, поэтому используется Tampermonkey.

1. Установите **Tampermonkey** из каталога расширений Яндекса:
   меню ☰ → «Дополнения» → внизу «Каталог расширений» → найдите **Tampermonkey** → «Добавить в Яндекс Браузер».
2. Нажмите на иконку Tampermonkey справа от адресной строки → **«Создать новый скрипт…»**.
3. В открывшемся редакторе выделите всё (Ctrl+A) и удалите.
4. Откройте файл `yandex/tender-tracker.local.user.js` в Блокноте (в нём уже прописаны ваша таблица и ключ),
   скопируйте весь текст (Ctrl+A, Ctrl+C) и вставьте в редактор Tampermonkey.
5. Сохраните: **Ctrl+S**. Скрипт появится в списке включённым.
6. Откройте любую закупку на zakupki.gov.ru — внизу справа появится кнопка **«📋 В учёт»**.

Как пользоваться:
- **«📋 В учёт»** → откроется панель, поля заполнятся сами (зелёные — распознаны автоматически) → «Сохранить».
- Если тендер уже сохранён, кнопка показывает **«✓ В учёте»** — откройте её, чтобы сменить статус.
- Меню Tampermonkey (иконка справа от адресной строки) на странице закупки:
  «📋 Добавить тендер», «⚙ Настройки таблицы» (адрес и ключ), «↻ Отправить неотправленное».
- Нет интернета — запись сохранится и отправится автоматически при следующем открытии площадки.

Если кнопка не появилась: проверьте, что скрипт «Учёт тендеров» включён в Tampermonkey, и обновите страницу.
Скрипт работает на zakupki.gov.ru, РТС-тендер, Сбер-АСТ, Росэлторг, B2B-Center, Фабрикант, ЭТП ГПБ, ТЭК-Торг,
lot-online, ZakazRF. Другую площадку можно добавить строкой `// @match https://адрес/*` в начале скрипта.

Пересобрать скрипт после правок (`yandex/userscript.src.js` или `tender-tracker/extract.js`):
```
powershell -ExecutionPolicy Bypass -File yandex\build.ps1
```
Получатся `tender-tracker.user.js` (публичный, без ключа) и `tender-tracker.local.user.js` (с ключом, не публикуется).

## 3. Google Таблица

**Уже сделано** для таблицы «Учет заявок_ТЕНЕДЕРов_v1»: скрипт установлен и развёрнут (лист «Тендеры»:
статусы-плашки, колонка «Осталось», подсветка сроков). Ниже — как подключить другую таблицу или сделать всё заново.

1. Откройте таблицу → меню **Расширения → Apps Script**.
2. Удалите всё в `Код.gs` и вставьте содержимое `google-apps-script.gs`.
3. В строке `const TOKEN = 'ЗАМЕНИТЕ-НА-СВОЙ-КЛЮЧ';` впишите свой ключ — любую фразу латиницей без пробелов.
   Ваша рабочая копия с ключом — `google-apps-script.local.gs` (не публикуется).
4. Сохраните (Ctrl+S), выберите функцию **setup** → «Выполнить» → разрешите доступ
   («Дополнительно» → «Перейти… (небезопасно)» → «Разрешить» — это нормально для своего скрипта).
5. **«Начать развертывание» → «Новое развертывание» → «Веб-приложение»**: запуск от имени **Я**, доступ **Все** → «Развернуть».
6. Скопируйте **URL веб-приложения** (…/exec) и впишите его вместе с ключом в `tender-tracker/config.js`
   (или в настройках расширения / Tampermonkey).

## Защита от дублей

- При открытии новой закупки расширение (Chrome и Яндекс) ищет её номер в таблице. Если тендер уже есть —
  открывается существующая запись с предупреждением «⚠️ Этот тендер уже есть в таблице»; «Сохранить» обновит её.
- Таблица сама склеивает записи с одинаковым номером (сравнение по цифрам): новая строка не создаётся,
  пустые поля не затирают заполненные.
- Номер, который всё же встречается в таблице дважды, подсвечивается оранжевым.
- Склеить уже существующие дубли — функция **dedupe** в Apps Script (остаётся самая свежая строка).

## 4. Напоминания в Telegram

Код — `telegram-reminders.gs`, второй файл того же проекта Apps Script. Проверка идёт раз в час на стороне Google
(компьютер может быть выключен). Присылает в рабочую группу: утреннюю сводку по будням с 9:00, срочные — за 24 ч и за 3 ч
до конца подачи, торги — накануне и в день торгов, итог недели — по понедельникам.

Подключение: «Настройки проекта» → «Свойства скрипта» → `TG_TOKEN` = токен бота от @BotFather;
бота добавить в группу и написать там `/start@адрес_бота`; выполнить функцию **tgSetup**.
Прислать сводку прямо сейчас — **tgTestDigest**, отключить напоминания — **tgStop**.

## 5. Ярлык таблицы на рабочем столе

`powershell -ExecutionPolicy Bypass -File shortcut\make-shortcut.ps1` — создаёт ярлык «Учёт тендеров» (таблица
открывается отдельным окном Chrome). Правой кнопкой по ярлыку → «Закрепить на панели задач».

## Как это работает

- Сохранили тендер или поменяли статус → строка сразу добавляется/обновляется в таблице.
- Направление одно: **расширение/скрипт → таблица**. Правки, сделанные прямо в таблице, обратно не возвращаются
  и при следующем изменении этого тендера будут перезаписаны.
- Один и тот же тендер, сохранённый и в Chrome, и в Яндексе, попадёт в таблицу двумя строками —
  ведите каждый тендер в одном браузере.
- Если поменяете код скрипта таблицы: **Развертывание → Управление развертываниями → ✏️ → Версия: «Новая версия» → Развернуть**
  (URL останется прежним). Перестроить лист под новое оформление с сохранением данных — функция **rebuild**.
- Ключ и URL не публикуйте: с ними любой может писать в таблицу.
